**Alert Settings (`/home/alerts`):**
- Lists each watched bathroom in the user's house with a single **Toggle Switch** (`เปิดรับแจ้งเตือนทาง Email` / `ปิดรับแจ้งเตือน`) that updates immediately via `PATCH /api/me/watchers/:bathroomId`.

## 9. Heatmap Modal (WA-16, WU-2)

Clicking **[ดู Heatmap]** opens a rounded (`14px`) modal displaying:
- DAPD Heatmap PNG (served through authenticated API `/api/fall-events/:id/heatmap`)
- บ้าน, ห้องน้ำ, วันเวลา (Asia/Bangkok), ความเชื่อมั่น AI, รุ่นโมเดล
